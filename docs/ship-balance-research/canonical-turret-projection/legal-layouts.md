# Current-legal maximum-packed loadout check

This separate check prevents confusing the original all-node hypothesis with actual fitting. It enumerates every maximum-cardinality homogeneous loadout of one weapon type on the native grid, using the correct merge controller for each footprint. FourHull-only capitals use one heavy gun per ordinary cell. Mothership uses corrected current positions. No new slots or mount types are granted.

`Worst` is the least edge gap across all allowed maximum-packed layouts and native-faction weapons of that size. `Best` first chooses each weapon’s best maximum packing, then reports the worst weapon. One-gun designs have no pair and are shown as a dash; they are not certified against hull geometry. Counts can differ by horizontal/vertical two-cell orientation. All bounds are full 3D spheres. Negative bounds are inconclusive, not clipping proof.
