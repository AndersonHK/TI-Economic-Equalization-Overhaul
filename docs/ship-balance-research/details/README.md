# Detailed research archive

Last reviewed: 2026-07-29

This directory holds narrow, evidence-heavy analyses. The parent
[ship-balance research index](../README.md) is the composed overview; topic
indexes here summarize the current interpretation and point to the detailed
facets that support it.

Detailed reports are not discarded when a later model proves more useful.
They are retained, scoped, and cited so that assumptions and changes in
perspective remain auditable.

## Topics

- [Reactors](reactors/README.md): thermodynamic, fuel-inventory, structural,
  cooling, and output-cap models.
- [Fuel cells](fuel-cells/README.md): electrochemistry, specific power,
  regenerative-system mass, radiator burden, and biological catalysts.
- [Weapons](weapons/README.md): conventional gun and railgun progression.
- [Aliens](aliens/README.md): module catalog, predefined ship layouts, and
  deferred balance hypotheses.
